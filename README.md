# homebrew-tap

Personal Homebrew tap for [elmastahsin](https://github.com/elmastahsin)'s tools.

## Usage

```
brew tap elmastahsin/tap
brew install --cask spine
```

## Casks

- **spine** — [Spine](https://github.com/elmastahsin/spine), a macOS menu bar posture app using AirPods head motion sensors.
